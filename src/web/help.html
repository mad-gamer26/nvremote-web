Getting started

NVDA Remote Web lets you control a Windows computer running the NVDA screen reader. You hear the remote computer's speech and sounds in your browser, and your keyboard controls it, just like NVDA's own Remote Access feature.

  1. On the Connect page, leave Server as nvremote.mad-gamer.com (or enter another NVDA Remote server), and enter a key, or choose Generate key.
  2. On the remote computer, open the NVDA menu, then Tools, then Remote Access, then Connect. Set Mode to Allow this computer to be controlled, Server to Use existing, and enter the same host and key.
  3. Choose Connect on this page. You will hear a sound when the remote computer joins.

This page can only control another computer. It can't be controlled itself, because web pages are not allowed to press keys on your device.

Controlling the remote computer

Once connected, choose Start controlling the remote computer, or press Shift+Escape. Every key you press then goes to the remote computer. Press Shift+Escape again to stop, and your keys stay on this device. You can change this key under Settings.

By default, controlling goes full screen. In Chrome and Edge, full screen lets keys like Alt+Tab, Escape and the Windows or Search key reach the remote computer instead of being used by this device. In other browsers some of those keys stay on this device. In full screen, holding Escape down for a couple of seconds also leaves full screen and stops controlling.

Control+Alt+Delete can never be sent from a keyboard, so use the Send Control+Alt+Delete button. It only works if the remote computer allows it (NVDA must be installed, not portable).

The NVDA key: the remote computer's NVDA key is Insert, or Caps Lock with the laptop layout. If your keyboard has neither, the Search, Windows or Command key can act as the NVDA key. Choose what it sends under Settings, Keyboard.

Use the key tester to check what each key on your keyboard sends.

Using a Chromebook

  • The Search key acts as the NVDA key by default.
  • The top row of keys (Back, Refresh and so on) is sent as F1 to F10 by default. Turn this off under Settings if you'd rather send the browser and media keys.
  • ChromeVox users: ChromeVox uses the Search key for its own commands, and gets those keys before any web page. While controlling, either turn ChromeVox off with Control+Alt+Z and let this page speak, or use ChromeVox's pass-through command (Search+Shift+Escape) before a key you want to send. Remember to turn ChromeVox back on when you stop controlling. Turning on "Also speak this page's messages with the browser voice" in Settings means you still hear connection messages while ChromeVox is off.

Using a screen reader on this device

The page works with screen readers, including NVDA, JAWS, Narrator, ChromeVox, VoiceOver and TalkBack. While controlling, the remote control area tells your screen reader to pass keys through (it is an application region), so NVDA and JAWS switch to focus mode automatically.

Your own screen reader's commands that use its modifier key, such as NVDA+T on this device, may still be used by your screen reader instead of being sent. Use the On-screen keys, or change "The Search, Windows or Command key sends" so a different key acts as the remote NVDA key.

By default the remote computer's speech uses this browser's voice, so it doesn't mix with your screen reader. You can instead send it to your screen reader under Settings, Speech.

Phones and tablets

Without a keyboard, use On-screen keys to press keys and common NVDA commands, and Type or paste text to send to type text. A Bluetooth keyboard works like any other keyboard.

Speech, sounds and braille

  • Speech: choose the browser's voice (recommended), your own screen reader, or no speech. Everything said is kept in the speech history on the Connect page.
  • Sounds: beeps and NVDA's standard sounds play here. Sounds from NVDA add-ons can't be played, because they only exist on the remote computer.
  • Mute remote silences the remote computer's speech and sounds without disconnecting.
  • Braille: turn on "Show the remote computer's braille display" in Settings to see the remote braille as braille characters on the Connect page.

Clipboard and typing text

  • When the remote computer sends its clipboard (NVDA+Control+Shift+C on the remote computer), the text appears on the Connect page, and is copied to this device if the browser allows it.
  • Send my clipboard sends this device's clipboard to the remote computer. Your browser may ask permission first.
  • Type it types text by pressing keys, and works best with English letters, numbers and punctuation. For other text, use Send as clipboard, then press Control+V on the remote computer.

Keys and certificates

The key is like a password: anyone who knows the server and key can join the session. Generate a new key for each session, and don't post it publicly.

NVDA Remote servers use encrypted connections. If a server's certificate can't be verified (which is common for servers run by individuals), you're asked whether to trust it, just as NVDA asks. Only trust servers you know. Trusted servers are listed under Settings, where you can forget them.

Troubleshooting

I hear nothing
Make sure the remote computer has connected (the status says "Connected to the remote computer"), that Mute remote is off, and try Test voice under Settings. Some browsers need a moment to load voices.
"The remote computer is not connected yet"
Check that both computers use exactly the same server, port and key.
Some keys don't reach the remote computer
Turn on "Go full screen while controlling", use Chrome or Edge, and check the key tester. Your own screen reader may be using the key; see Using a screen reader on this device.
A key seems stuck down on the remote computer
Press and release that key again while controlling, or stop and start controlling.
