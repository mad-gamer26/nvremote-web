NVDA Remote Web

Control a Windows computer running NVDA from this browser. You hear the remote computer's speech and sounds here, and your keyboard controls it.

Status: Not connected

Connect to a remote computer

The NVDA Remote server both computers use. You can also paste an NVDA Remote link (starting with nvdaremote://) here.

Usually 6837.

Use the same key on both computers. Anyone with the key and server can join, so keep it private.

How to set up the remote computer
  1. On the remote computer, make sure NVDA 2025.1 or later is running.
  2. Open the NVDA menu (NVDA+N), then Tools, then Remote Access, then Connect.
  3. Set Mode to Allow this computer to be controlled.
  4. Set Server to Use existing.
  5. In Host, type the same server as above. If the port is not 6837, add a colon and the port, for example example.com:1234.
  6. In Key, type the same key as above, then press OK.
  7. You will hear a sound here when the remote computer joins.

Or, once you're connected, copy the NVDA Remote link from "Invite the remote computer" and open it on the remote computer.

Using the older NVDA Remote add-on instead? It works too: choose Allow this machine to be controlled in its Connect dialog.

    Speech from the remote computer

    The browser's voice stops instantly when the remote computer interrupts speech, like NVDA does. Your own screen reader can't be interrupted by a web page, so speech may pile up.

    Keyboard

    Chromebooks have no Insert or Caps Lock key, so by default the Search key acts as the NVDA key. The Windows key is also available under On-screen keys.

    Back is F1, Forward is F2, Refresh is F3, and so on.

    Full screen lets keys like Alt+Tab, Escape and the Search key reach the remote computer in Chrome and Edge. Without it, the browser keeps some keys for itself.
